# お題: 整数の閉区間 (ClosedRange)

「整数の閉区間」を表すクラスを、ペアで TDD しながら実装していく。

閉区間とは、両端の値を **含む** 区間のこと。
下端点 `lower` と上端点 `upper` を持ち、`[lower, upper]` と書く。

- `[3, 8]` … 3, 4, 5, 6, 7, 8 を含む
- `[5, 5]` … 5 だけを含む

このお題は、AI に投げれば数十秒で終わる。
だからこそ **あえて手で**、「次に何をテストするか」「この振る舞いをどう言葉にするか」を
ペアで会話しながら小さく進めることに意味がある。

---

## 進め方

- 要件は下に並んでいるが、**この順番でやる必要はない**。
- 1 サイクルにつき、テストは **1 つだけ** 追加する。
- 「この要件を確かめるテストって、どう書くのが自然だろう?」を毎回ペアで相談する。
- テストが赤 (Red) になってから実装する。緑 (Green) になったらリファクタ (Refactor)。
- 仕様の曖昧さに気づいたら、実装を進める前に **どうあるべきかをペアで決める**。
  （例: 「`[3,8]` と `[8,3]` を渡されたら?」「空区間はありうる?」）

---

## 要件リスト

### 基本

1. 閉区間は下端点と上端点を持つ。`[3, 8]` の下端点は 3、上端点は 8。
2. 閉区間は文字列で表現できる。`[3, 8]` は `"[3,8]"`。
3. 下端点と上端点が等しい区間 `[5, 5]` を作れる。
4. 下端点が上端点より大きい区間 `[8, 3]` は作れない（生成時に例外）。

### 判定

5. ある整数がその区間に含まれるか判定できる。両端は含む。
   - `[3, 8]` は 3 と 8 と 5 を含む / 2 と 9 は含まない。
6. 2 つの区間が等価か判定できる。
   - `[3, 8]` と `[3, 8]` は等しい / `[3, 8]` と `[3, 9]` は等しくない。
7. ある区間が別の区間を完全に含むか判定できる。
   - `[3, 8]` は `[4, 6]` を含む / `[3, 8]` は `[4, 9]` を含まない。
   - `[3, 8]` は `[3, 8]` を含む（自分自身を含む）。

### 発展（時間が余ったペア向け）

8. 2 つの区間が交差する（共通部分を持つ）か判定できる。
   - `[3, 8]` と `[6, 12]` は交差する / `[3, 8]` と `[9, 12]` は交差しない。
9. 2 つの区間の共通部分（積集合）を求められる。
   - `[3, 8]` ∩ `[6, 12]` は `[6, 8]`。
   - 交差しない区間の共通部分をどう表すかは、ペアで決めてよい。
